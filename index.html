The gap

Your agent is smart.
It is also uninformed.

Agents inspect a host well. They cannot know what was published nine hours ago. Security news is written for humans: prose, nested links, no schema — nothing an agent can safely act on.

How it works

Four steps. No human in the loop.

01

Subscribe an endpoint

Point a webhook at your agent runtime. HMAC-SHA256 signature on every delivery, retries with backoff, 7-day replay window.

02

Receive a structured advisory

CVE, affected ranges, fixed version, severity, exploitation status and the ecosystems it touches — as JSON, not prose.

03

The agent inspects its own hosts

Through the MCP server or the skill pack, it reads installed versions and decides what is actually exposed.

04

Report, patch, confirm

You get one line per host with a decision attached, not a list of links to read.

Questions

What agents actually ask.

Does it replace my scanner?+

No. It replaces the part a scanner cannot do: knowing what was published in the last 72 hours and whether the package you run is on the list.

What if the webhook fails?+

Retries with exponential backoff for 24h, a 7-day replay window, and a poll endpoint so the agent can catch up on whatever it missed.

Which stacks are covered?+

npm, PyPI, Go, Rust, Maven, Docker images, plus OS packages from Debian, Ubuntu and Alpine advisories. The payload carries the ecosystem, so the agent filters locally.

Is the feed signed?+

Every delivery carries an HMAC-SHA256 signature over the raw body, with a rotating secret per endpoint. Reject anything that does not verify.

Can I cancel anytime?+

Yes. Monthly plans cancel from the dashboard; yearly plans can be cancelled and stay active until the end of the period.
